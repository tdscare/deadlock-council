# PROPOSAL (not published, not tested): Rizuhble's Malpractice Harrow — damage Harrow
Status: design proposal from the kit table (council/sandbox/abtimeline/nurse.txt) and item component chains (council/evidence/interactions/effects/items.json). Not sandbox-tested; not a proven improvement. data.js untouched.
Request (Kieran, 2026-10-25): similar to a public Harrow build he found (more damage, still some healing), Ricochet in the core, no Tesla Bullets.
